- assets/* (place your images here; replace placeholders)

## How to personalize
1. Replace the placeholder texts with your real name, bio, achievements.
2. Add your images to `assets/` and update `gallery.html` figure blocks.
3. Change social links in `contact.html`.
4. Replace `mailto:your-email@example.com` in `script.js` with your email OR configure a form backend (Formspree / Netlify Forms).

## Accessibility & Meta
- Each page includes viewport meta and description meta tags.
- Semantic HTML (header, main, footer, sections) is used.

## Deployment (GitHub Pages)
1. Initialize git in your folder and push to a GitHub repo.
2. In GitHub repo -> Settings -> Pages -> choose the main branch / root folder.
3. Wait a minute; your site will be available at `https://<username>.github.io/<repo>/`.

(Alternative: deploy to Netlify or Vercel by connecting the repo — both are free for static sites.)
