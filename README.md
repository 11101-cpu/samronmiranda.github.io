# 🌐 Personal Portfolio Website

A multi-page personal portfolio site built from scratch with HTML, CSS, and vanilla JavaScript. This was my first web project — I built it to learn the fundamentals of front-end development and to have a live, working site I could keep improving over time.

🔗 **Live site:** [https://samronmiranda.github.io/](https://11101-cpu.github.io/samronmiranda.github.io/)

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript (vanilla)
- GitHub Pages (deployment)

## 🎨 Features

Here's what you'll find on the site:

- **Home**: Landing page introducing who I am and what I do.
- **About**: A page dedicated to my background, skills, and interests.
- **Gallery**: A portfolio/gallery section showcasing images and work.
- **Contact**: A contact page with a form to reach out to me.
- **Responsive Layout**: The site adapts across different screen sizes using custom CSS.
- **Navigation**: Consistent navigation across all pages for easy movement between sections.

## 🧭 The Process

I started by planning the pages I needed: Home, About, Gallery, and Contact. Rather than building everything in one file, I separated concerns from the start — `index.html`, `about.html`, `gallery.html`, and `contact.html` for structure, `styles.css` for design, and `script.js` for interactivity.

Once the page skeletons were in place, I focused on styling — getting a consistent layout, color scheme, and typography across every page so the site felt like one cohesive product rather than four separate pages stitched together.

After the core structure and design were solid, I added the gallery section to showcase images, and built out the contact page with a working form. Along the way, I documented my file structure and personalization steps in the README so the project would be easy to explain and extend later.

## 📚 What I Learned

Building this project taught me a lot about how real websites are structured and put together.

- Learned to use semantic elements to write cleaner, more accessible markup.

**CSS Layout & Responsiveness**
- Practiced using layout techniques to make pages adapt across screen sizes.
- Got more comfortable with consistent styling across multiple pages.

**JavaScript Fundamentals**
- Used JavaScript to add interactivity, like handling form input on the contact page.

**Project Organization**
- Understood the value of separating HTML, CSS, and JS into their own files instead of mixing everything together.

**Deployment**
- Learned how GitHub Pages works and how to deploy a static site directly from a repository.

## 📈 Overall Growth
